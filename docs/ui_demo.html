这些服务器都是干嘛的？

中继服务器：你每天刷的帖子来自这里。Costr 连着这些中继，实时收发大家发的文字、转发和点赞。

搜索中继：专门支持全文搜索的中继。你在搜索页搜关键词时，只问这几台。

索引中继：收录了"几乎所有人"的个人资料（昵称、头像、简介），本地没有时来这取。

Blossom 图床：你发帖时上传的图片和视频存在这里。上传时按顺序逐个试，谁先成功用谁。

关于 Costr

Costr

Costr = Chinese Nostr

更适合中文用户的 Nostr 开源社交客户端

没有人能删你的帖子

你发的帖子分布在全网多台服务器上，没有任何人——包括 Costr 自己——能删除、封号或限流。说出去的话，没人能替你收回。

匿名，一把钥匙就是身份

不用手机号、不用邮箱、不实名。一串钥匙就是你的整个账号，不绑定任何现实身份。搭配 VPN 代理服务一起用，连中继都看不到你的真实网络地址，匿名保障更高。

你的钥匙，你做主

私钥只存在你这台手机里，不上传任何服务器。没有公司能替你发帖，也没有平台能封你——像自己开了个广播站。

简单、克制、不打扰

信息是公开的，但体验是安静的。默认值就是最好的设置，开箱即用，不用折腾一堆开关。

Nostr 协议原理

每个 app 同时连多台中继；你把帖子写进自己的「发件箱」中继，别人去你的发件箱取。没有中心服务器。

发帖＝写进你的「发件箱」中继

每个 Nostr 用户为自己挑几台中继服务器，当作自己的「发件箱」（outbox）。你发的帖子会写进你自己的发件箱中继——就像在自己开的公告栏上贴告示，而不是漫天撒网。任何一台掉线、跑路，其他中继照常替你保管分发，帖子不会丢、不会断。

看帖＝去别人的「发件箱」取

想看 A 的帖子，就去 A 的发件箱中继订阅——而不是等告示飞到你面前。A 用一张「中继清单」（NIP-65）告诉全网「我的发件箱在哪几台中继」，Costr 按这张清单找过去取。你关注了谁，就去谁的发件箱取。私信等只给特定人的内容，则写到对方的「收件箱」（inbox）中继（NIP-17），只有对方能收到。没有中心服务器，谁也拦不下这条路径。

退出登录？

当前账号的私钥将从这台手机移除（其他已添加账号不受影响）。本地数据（帖子缓存、关注列表）会保留，下次用同一把私钥登录即可恢复。

想彻底注销这个账号？去中心化里没人能删你的号——但你可以不再用这把钥匙，它就静默下去了。

自定义中继服务器

这是高级功能。这里的服务器决定你能刷到的帖子从哪来、你发的帖子发到哪去。只有当某台服务器长期处于离线状态时，才需要来自定义。如果列表配置错误，可能刷不出新帖子，或发帖失败。不确定怎么改的话，保持默认就好。
